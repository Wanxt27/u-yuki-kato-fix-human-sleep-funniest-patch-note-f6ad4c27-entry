A make.fun entry for [Fix Human Sleep: Funniest Patch Note](https://make.fun/bounty/u-yuki-kato-fix-human-sleep-funniest-patch-note-f6ad4c27).

`main.ts` (Node 22, stdlib only) writes one line of patch notes — 103 characters — to `/output/entry.txt`:

> Fixed: human sleep no longer crashes at 3 a.m. — the 'just one more video' process has been terminated.

The joke: sleep is software, and it crashes at 3 a.m. because a "just one more video" background process is still running — so the fix terminates that process.

Run it with:

```sh
node main.ts
```
